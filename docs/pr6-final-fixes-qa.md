# PR #6: единый текст, полное завершение и минуты

Версия остаётся 0.5.0 (6), ветка feat/voice-capture. Нового PR, миграции схемы, LLM, изменений диктовочного движка, Widgets или Snooze нет. Пользователь подтвердил предыдущую сборку на iPhone 13; эти исправления пока не проверены физически.

## Текст голосовой задачи

На экране одно редактируемое поле «Текст задачи». Голос, дополнительная диктовка и клавиатура меняют этот текст; парсер только предлагает параметры. Скрытого fields.title больше нет. При нажатии Create снимаются текущий текст и показанные дата/alarm/recurrence; последующие интерпретации не меняют снимок. Проверка пустоты сохраняется, само название передаётся дословно, включая переносы и крайние пробелы. Только голосовой путь включает preserveTitleWhitespace; ручное создание сохраняет прежнюю нормализацию.

ReminderDraft.sourceText/title и ReminderInterpreter сохранены для PR #7. Ручные дата, будильник и повторение имеют приоритет над повторной интерпретацией. Защита сессий диктовки от поздних callback не менялась.

## Завершение

- Галочка в строке, Done контекстного меню и Done редактора вызывают существующий finishSeries. Для любого типа задачи это полное завершение, сохранение completedAt, отмена будущего сигнала и переход в Completed. История предыдущих выполнений остаётся. Calendar использует прежнюю логику завершения серии.
- CompleteTaskIntent не менялся. Системный Stop выполняет один экземпляр серии и ставит следующий; одноразовую задачу завершает полностью. Старые повторные intents после полного завершения не создают сигналов.
- Actions не выполняет задачу, Turn off alarm только отключает сигнал.
- Ошибка отмены не отменяет сохранённое завершение: остаются ошибка и маркер восстановления, foreground refresh повторяет отмену.

## Минуты

RecurrenceRule.Unit.minutes — дополнительный стабильный Codable ID. Старые IDs и поля не меняются. Интервал 1–1440 минут; общий Stepper учитывает предел выбранной единицы. Вычисление использует elapsed seconds (N × 60), тот же исходный якорь и пропуск уже прошедших периодов, что и часы. Полночь/DST не превращают его в календарное прибавление.

Одновременно ожидает одно выполнение и один AlarmKit-сигнал; следующий — после системного Stop. Нет фонового таймера или обещания автономной цепочки. Для минут и часов Calendar хранит только исходное событие с пояснением; EKRecurrenceRule не создаётся. Остальные календарные правила прежние.

## Регрессионные проверки

Unit-тесты покрывают снимок видимого текста при запоздавшей интерпретации, буквальное сохранение через ReminderStore/повторное открытие, ручные параметры и дополнительную диктовку; полное завершение серии после системного Stop, повторные intents и ошибку отмены; 1/5/30 минут, полночь, исходную сетку времени, DST, границы, Codable старого hours/нового minutes, отключённый сигнал и отсутствие дубликатов. Миграционные fixtures прежних версий сохраняются.

Предыдущий CI выявил ошибочное снятие dirty-маркера метаданных после schedule error. Исправление оставляет title/sound/actions непроверенными до успешного retry: совпавшей даты недостаточно. Существующий регрессионный тест сохранён.
